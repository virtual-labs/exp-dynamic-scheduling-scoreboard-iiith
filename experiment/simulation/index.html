How to Use This Simulator

📝 Step 1: Build Your Instruction Sequence

Add instructions using the form below. Each instruction requires:

  • Instruction Type: Choose from arithmetic (ADDD, SUBD, MULTD, DIVD), integer (DADD, DSUB), logical (AND, OR, XOR), or memory operations (LD, SD)
  • Registers: Select destination and source registers (F0-F31 for floating-point, R0-R31 for integer)
  • Reordering: Use ↑/↓ buttons to change instruction order, or ✕ to remove instructions

▶️ Step 2: Start the Simulation

Once you've added at least one instruction, click "Start Simulation" to begin. The simulator will display three key tables:

  • Instruction Status: Shows each instruction's progress through the 4 scoreboarding stages
  • Functional Unit Status: Displays the state of each functional unit (Integer, FP Adder, FP Multiplier, FP Divider)
  • Register Result Status: Tracks which functional unit will write to each register

🎯 Step 3: Execute Instructions Manually

Click on cells in the Instruction Status table to advance instructions through these stages:

  1. Issue: Instruction is issued if the functional unit is free and no WAW hazard exists
  2. Read Operands: Operands are read when ready (no RAW hazard)
  3. Execution Complete: Execution finishes after the required number of cycles
  4. Write Result: Result is written if no WAR hazard exists

Note: You must complete all pending actions in the current cycle before advancing to the next cycle.

💡 Step 4: Learn from Feedback

The simulator provides real-time feedback:

  • If you click prematurely, you'll see an explanation of why the action is blocked (e.g., "RAW hazard: waiting for F2")
  • Click "Hint" to get suggestions on what actions can be performed
  • Use "Next Cycle" to advance time once all pending actions are complete

💡 Tip: Start with simple instruction sequences (2-3 instructions) to understand the basics, then try more complex scenarios with dependencies and hazards.
